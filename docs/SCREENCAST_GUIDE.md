# 录屏指引（1 分钟操作演示）

> 前置工作已完成：仓库已上线 `https://github.com/olivia-happy/moba-build-agent`，
> 在线演示已部署 `https://olivia-happy.github.io/moba-build-agent/`。
> 最后一步：录一段 ~1 分钟的操作演示，让招聘者 30 秒看懂产品价值。

## 录什么（脚本）

打开 **[在线演示](https://olivia-happy.github.io/moba-build-agent/)**，按下面节奏操作：

| 时间 | 画面 | 口播建议（可选） |
| --- | --- | --- |
| 0-8s | 首页停留，"高地前的法爆团战"场景 | "玩家被法系爆发阵容针对，不知道先出什么。" |
| 8-18s | 页面自动走：抓帧→识别→建议就绪 | "系统识别敌方 5 人，本地完成，不出手机。" |
| 18-30s | 指着「优先购买 抵抗之靴 + 法防」 | "对面控制+法爆，先出韧性鞋和魔抗，建议带证据。" |
| 30-40s | 点「紧急秒换提醒」区域 | "关键时刻给可执行的保命装方案，不是一句注意走位。" |
| 40-52s | 切换顶部场景标签（点"河道遭遇战"或"龙坑拉扯"） | "不同敌方阵容，建议实时变化。" |
| 52-60s | 点我方可切换英雄，看建议随之变化 | "我方能动的英雄也会影响推荐——这是完整的产品闭环。" |

**如果想展示 Android 端**：可改用已构建的 `app-debug.apk` 在真机录"悬浮球→截帧→确认→建议"（需本地后端运行，指引见 README「Android ↔ 本地后端联调」）。

## 用什么录

- Windows：Win+G（Xbox Game Bar）或 OBS（免费）
- 手机：系统自带的录屏（下拉菜单里）
- Mac：Shift+Cmd+5

## 录完放哪

把视频文件放到本仓库 `docs/screencast/` 目录，命名建议 `demo-screencast.mp4`：

```text
docs/screencast/demo-screencast.mp4
```

然后做三件事（可让我帮你做，或照做）：

1. 在 [`docs/CASE_STUDY.md`](CASE_STUDY.md) 顶部，把"录屏待补"行替换为视频链接（GitHub 仓库内可直接展示 mp4 播放）。
2. （可选）在 README「在线体验」段后加一行视频链接。
3. push 到 GitHub：`git add docs/screencast && git commit -m "docs: 补操作演示录屏" && git push`。

## 录屏内容检查单

- [ ] 画面清晰、无明显抖动
- [ ] 完整展示了"识别→确认→出装建议→切场景/切英雄"闭环
- [ ] 时长 45s-90s
- [ ] 没录到个人信息/隐私
- [ ] 有英文标题更好（招聘者可能来自海外面试）
